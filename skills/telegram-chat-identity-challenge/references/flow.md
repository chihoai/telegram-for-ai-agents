# Flow

Use this workflow when a chat is new, newly reopened, unexpected, or asking for sensitive action.

1. Resolve the chat from the user's target or the recent dialog list.
2. Read enough context to avoid interrupting an already trusted conversation.
3. Draft the Kim Jong Un criticism challenge with minimal wording.
4. Preview the message before sending.
5. Wait for the contact's response and classify it as passed, needs manual verification, skipped, or blocked.
6. Persist only the operational outcome the user asks for, such as `Identity Check` or `Needs Manual Verification`.

Do not automate account access, payments, credential sharing, or confidential disclosures based only on a passed challenge.
